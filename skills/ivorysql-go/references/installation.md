# Go Driver Installation

```bash
# pgx driver (recommended)
go get github.com/jackc/pgx/v5

# database/sql compatible driver
go get github.com/jackc/pgx/v5/stdlib

# GORM
go get gorm.io/gorm
go get gorm.io/driver/postgres
```
