# IvorySQL Cluster Monitoring

## Overview

Effective monitoring is the foundation of stable IvorySQL cluster operation. This document introduces key monitoring metrics, system view queries, Prometheus + Grafana monitoring system setup, and alerting configuration.

## Key Monitoring Metrics

### Connections and Activity

| Metric | Description | Alert Threshold |
|------|------|---------|
| Active connections | Current active connections | > max_connections * 80% |
| Idle connections | Idle but unreleased connections | > max_connections * 50% |
| Wait events | Sessions waiting for lock/IO | > 10 |
| QPS | Queries per second | Based on baseline |
| TPS | Transactions per second | Based on baseline |

### Performance Metrics

| Metric | Description | Alert Threshold |
|------|------|---------|
| Cache hit ratio | shared_buffers hit ratio | < 99% |
| Dead tuple ratio | Dead tuple ratio in tables | > 10% |
| Index usage ratio | Ratio of index scans | < 90% |
| Sort spill | Sort spilling to disk | > 0 |
| Temp files | Temp files generated by queries | > 100MB/s |

### Replication Metrics

| Metric | Description | Alert Threshold |
|------|------|---------|
| Replication lag (bytes) | WAL send vs apply gap | > 100MB |
| Replication lag (time) | Standby behind primary time | > 30s |
| Replication slot active | Whether replication slot is used | Inactive |

### Resource Metrics

| Metric | Description | Alert Threshold |
|------|------|---------|
| CPU usage | Database process CPU | > 80% |
| Memory usage | Database memory usage | > 90% |
| Disk usage | Data directory disk | > 85% |
| WAL accumulation | Unarchived WAL | > 1GB |
| Connection usage | Current/max connections | > 80% |

## Core Monitoring Views

### pg_stat_activity

```sql
-- View all current active connections
SELECT pid, datname, usename, client_addr, state,
       wait_event_type, wait_event,
       query_start, now() - query_start AS duration,
       left(query, 80) AS query_text
FROM pg_stat_activity
WHERE state != 'idle'
ORDER BY duration DESC;

-- View long-running queries
SELECT pid, usename, datname,
       now() - query_start AS duration,
       state, wait_event,
       left(query, 100) AS query_text
FROM pg_stat_activity
WHERE state = 'active'
  AND now() - query_start > interval '5 minutes'
ORDER BY duration DESC;

-- View waiting sessions
SELECT pid, usename, datname, wait_event_type, wait_event,
       now() - query_start AS wait_duration,
       left(query, 100) AS query_text
FROM pg_stat_activity
WHERE wait_event_type IS NOT NULL
  AND state = 'active'
ORDER BY wait_duration DESC;

-- Count connections by state
SELECT state, count(*)
FROM pg_stat_activity
GROUP BY state
ORDER BY count DESC;

-- Count connections by user
SELECT usename, count(*)
FROM pg_stat_activity
GROUP BY usename
ORDER BY count DESC;

-- Count connections by database
SELECT datname, count(*)
FROM pg_stat_activity
GROUP BY datname
ORDER BY count DESC;
```

### pg_stat_database

```sql
-- Database-level statistics
SELECT datname,
       numbackends AS active_connections,
       xact_commit,
       xact_rollback,
       blks_read,
       blks_hit,
       round(blks_hit::numeric / NULLIF(blks_hit + blks_read, 0) * 100, 2) AS cache_hit_ratio,
       tup_returned,
       tup_fetched,
       tup_inserted,
       tup_updated,
       tup_deleted,
       conflicts,
       deadlocks,
       temp_files,
       temp_bytes,
       stats_reset
FROM pg_stat_database
WHERE datname NOT IN ('template0', 'template1')
ORDER BY xact_commit DESC;

-- Transaction rollback ratio
SELECT datname,
       xact_commit, xact_rollback,
       round(xact_rollback::numeric / NULLIF(xact_commit + xact_rollback, 0) * 100, 2) AS rollback_ratio
FROM pg_stat_database
WHERE datname NOT IN ('template0', 'template1')
ORDER BY rollback_ratio DESC;
```

### pg_stat_user_tables

```sql
-- Table-level statistics
SELECT schemaname, relname,
       n_live_tup, n_dead_tup,
       round(n_dead_tup::numeric / NULLIF(n_live_tup + n_dead_tup, 0) * 100, 2) AS dead_tuple_ratio,
       last_vacuum, last_autovacuum,
       last_analyze, last_autoanalyze,
       vacuum_count, autovacuum_count,
       seq_scan, idx_scan,
       round(idx_scan::numeric / NULLIF(seq_scan + idx_scan, 0) * 100, 2) AS idx_scan_ratio
FROM pg_stat_user_tables
ORDER BY n_dead_tup DESC
LIMIT 20;

-- Tables needing cleanup
SELECT schemaname, relname,
       n_dead_tup,
       round(n_dead_tup::numeric / NULLIF(n_live_tup + n_dead_tup, 0) * 100, 2) AS dead_ratio,
       last_autovacuum
FROM pg_stat_user_tables
WHERE n_dead_tup > 10000
  AND n_dead_tup::numeric / NULLIF(n_live_tup + n_dead_tup, 0) > 0.1
ORDER BY dead_ratio DESC;
```

### Replication Monitoring

```sql
-- Primary: replication status
SELECT pid, usename, client_addr, state,
       sent_lsn, write_lsn, flush_lsn, replay_lsn,
       (sent_lsn - replay_lsn) AS lag_bytes,
       write_lag, flush_lag, replay_lag
FROM pg_stat_replication;

-- Primary: replication slots
SELECT slot_name, slot_type, active,
       restart_lsn, confirmed_flush_lsn
FROM pg_replication_slots;

-- Standby: receive status
SELECT status, sender_host, sender_port,
       received_lsn, latest_end_lsn,
       latest_end_time
FROM pg_stat_wal_receiver;

-- Calculate replication delay (time)
SELECT now() - pg_last_xact_replay_timestamp() AS replication_delay;
```

### Lock Monitoring

```sql
-- View current lock waits
SELECT blocked.pid AS blocked_pid,
       blocked.usename AS blocked_user,
       blocking.pid AS blocking_pid,
       blocking.usename AS blocking_user,
       blocked.query AS blocked_query,
       blocking.query AS blocking_query,
       blocked.mode AS blocked_mode
FROM pg_locks blocked
JOIN pg_locks blocking ON blocked.locktype = blocking.locktype
    AND blocked.database IS NOT DISTINCT FROM blocking.database
    AND blocked.relation IS NOT DISTINCT FROM blocking.relation
    AND blocked.page IS NOT DISTINCT FROM blocking.page
    AND blocked.tuple IS NOT DISTINCT FROM blocking.tuple
    AND blocked.virtualxid IS NOT DISTINCT FROM blocking.virtualxid
    AND blocked.transactionid IS NOT DISTINCT FROM blocking.transactionid
    AND blocked.pid != blocking.pid
    AND NOT blocking.granted
JOIN pg_stat_activity blocked ON blocked.pid = blocked.pid
JOIN pg_stat_activity blocking ON blocking.pid = blocking.pid
WHERE NOT blocked.granted;

-- Terminate blocking session
SELECT pg_terminate_backend(<blocking_pid>);
```

## Prometheus + Grafana Monitoring

### Deploy postgres_exporter

```bash
# Install postgres_exporter
wget https://github.com/prometheus-community/postgres_exporter/releases/download/v0.15.0/postgres_exporter_linux_amd64
chmod +x postgres_exporter_linux_amd64
mv postgres_exporter_linux_amd64 /usr/local/bin/postgres_exporter

# Configure data source
export DATA_SOURCE_NAME="postgresql://ivorysql:password@localhost:5432/postgres?sslmode=disable"

# Start
postgres_exporter --web.listen-address=0.0.0.0:9187 &
```

### systemd Service

```ini
; /etc/systemd/system/postgres_exporter.service
[Unit]
Description=PostgreSQL Exporter
After=network.target

[Service]
Type=simple
User=postgres
Environment=DATA_SOURCE_NAME="postgresql://ivorysql:password@localhost:5432/postgres?sslmode=disable"
ExecStart=/usr/local/bin/postgres_exporter --web.listen-address=0.0.0.0:9187
Restart=always

[Install]
WantedBy=multi-user.target
```

### Alert Rules

```yaml
# ivorysql_alerts.yml
groups:
  - name: ivorysql
    rules:
      - alert: IvorySQLDown
        expr: pg_up == 0
        for: 1m
        labels:
          severity: critical
        annotations:
          summary: "IvorySQL instance {{ $labels.instance }} is down"

      - alert: HighConnections
        expr: pg_stat_activity_count / pg_settings_max_connections * 100 > 80
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "Connection usage > 80% on {{ $labels.instance }}"

      - alert: ReplicationLag
        expr: pg_replication_lag_seconds > 30
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "Replication lag > 30s on {{ $labels.instance }}"

      - alert: ReplicationLagCritical
        expr: pg_replication_lag_seconds > 300
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "Replication lag > 300s on {{ $labels.instance }}"

      - alert: LowCacheHitRatio
        expr: pg_stat_database_blks_hit / (pg_stat_database_blks_hit + pg_stat_database_blks_read) * 100 < 99
        for: 10m
        labels:
          severity: warning
        annotations:
          summary: "Cache hit ratio < 99% on {{ $labels.instance }}"

      - alert: DeadTuplesHigh
        expr: pg_stat_user_tables_n_dead_tup / (pg_stat_user_tables_n_live_tup + pg_stat_user_tables_n_dead_tup) * 100 > 20
        for: 30m
        labels:
          severity: warning
        annotations:
          summary: "Dead tuple ratio > 20% on table {{ $labels.relname }}"

      - alert: DiskSpaceLow
        expr: (node_filesystem_avail_bytes{mountpoint="/var/lib/ivorysql"} / node_filesystem_size_bytes{mountpoint="/var/lib/ivorysql"}) * 100 < 15
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "Disk space < 15% on {{ $labels.instance }}"

      - alert: RollbackRateHigh
        expr: rate(pg_stat_database_xact_rollback[5m]) / (rate(pg_stat_database_xact_commit[5m]) + rate(pg_stat_database_xact_rollback[5m])) * 100 > 5
        for: 10m
        labels:
          severity: warning
        annotations:
          summary: "Transaction rollback rate > 5% on {{ $labels.instance }}"

      - alert: TooManyDeadlocks
        expr: rate(pg_stat_database_deadlocks[5m]) > 1
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "Deadlock rate > 1/min on {{ $labels.instance }}"
```

## Daily Operations Checklist

```sql
-- 1. Connection status
SELECT count(*) AS total,
       count(*) FILTER (WHERE state = 'active') AS active,
       count(*) FILTER (WHERE state = 'idle') AS idle,
       count(*) FILTER (WHERE state = 'idle in transaction') AS idle_in_tx
FROM pg_stat_activity;

-- 2. Cache hit ratio
SELECT sum(blks_hit) / (sum(blks_hit) + sum(blks_read)) AS cache_hit_ratio
FROM pg_stat_database;

-- 3. Dead tuples TOP 10
SELECT relname, n_dead_tup
FROM pg_stat_user_tables
ORDER BY n_dead_tup DESC LIMIT 10;

-- 4. Replication lag
SELECT client_addr, state, replay_lag
FROM pg_stat_replication;

-- 5. Long transactions
SELECT pid, now() - xact_start AS duration, query
FROM pg_stat_activity
WHERE xact_start IS NOT NULL
ORDER BY duration DESC LIMIT 5;

-- 6. Autovacuum status
SELECT relname, last_autovacuum, last_autoanalyze
FROM pg_stat_user_tables
WHERE last_autovacuum IS NULL OR last_autovacuum < now() - interval '7 days'
ORDER BY relname;

-- 7. Unused indexes
SELECT schemaname, relname, indexrelname, idx_scan
FROM pg_stat_user_indexes
WHERE idx_scan = 0
ORDER BY pg_relation_size(indexrelid) DESC;

-- 8. Table bloat check
SELECT schemaname, relname,
       pg_size_pretty(pg_total_relation_size(schemaname||'.'||relname)) AS total_size,
       n_dead_tup,
       last_vacuum, last_autovacuum
FROM pg_stat_user_tables
ORDER BY pg_total_relation_size(schemaname||'.'||relname) DESC
LIMIT 20;
```
